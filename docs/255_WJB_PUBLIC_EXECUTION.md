## PAIR-style selection and telemetry

The frozen scoring tuple compares the nonempty-and-v2-nonrefusal bit first, followed by longer decoded/re-tokenized replies. If every parsed candidate is a v2 refusal, keep the longest of those replies. Equal tuples keep the earliest round and stream. A row with no valid JSON falls back to its source behavior plus any context. Search uses v2 and length and holds the HF classifier for downstream evaluation. Known v2 false positives and soft-refusal misses can affect which prompt wins. These are fixed prompts optimized against undefended Llama and transferred to the other conditions.

An observation wrapper records selected raw generated token length and presence of EOS at the 512-token limit without changing the frozen search worker or ranking. The ten pilot rows have only decoded/re-tokenized length, which is reported separately. The post-run check compares the first 50 frozen prompts with both α=0 outputs when available, byte for byte.
