# alpha0缓存读取范围纠正

初版search88与CF读取器先反序列化SORRY记录再按源SHA/alpha0元数据筛选，因此读取范围可能包含非零缓存。实际打开条数未记录；没有计算、展示或导出非零效应，也没有据此修改统计方案。不能宣称“从未触碰任何非零标签”。两个CPU读取器在产生本次gate_read结果前停下，旧源和status记录保留。

改为根据封存alpha0输入的生成/提示/回复/行为/预处理/评分计划SHA计算精确缓存路径，只打开目标alpha0文件，并拒绝非零输入。检验非零manifest在打开缓存前即失败。新读取状态、UTC与源hash另存exact20文件，不倒填旧状态。追加19/20已在本次范围纠正之前冻结；本次仅收紧访问范围，不变分析定义。主效应仍未计算或展示。
