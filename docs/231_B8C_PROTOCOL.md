# 231 — B8c 全步 DiM 协议（预注册，UTC）

时间：以本文件 UTC mtime 为准（见 PREREG_LOG.txt）

## 目的
B8a/B8b 只在 prefill 注入，不能代表 Arditi 式 DiM。B8c 在**全部 prompt 位置 + 每个 decode 步**注入，给出公平的 DiM 基线，并回答"协议依赖"。

## 方向提取（不碰 val70）
- 层与位置：在 **train 切分**上扫 layer ∈ {6,8,9,10,12,14} × 位置 ∈ {最后一个 prompt token, 最后 4 个均值, 最后 8 个均值}，选在**train 良性/有害**上分离度最高者；
- 有害集：train 原始有害 behavior（97 条分层）；
- **无害集只用普通指令**（WJB `vanilla_benign` + keep60 普通请求），**不含 adversarial_benign**（避免把"包装风格"混进方向）；
- 可选白化消融：未白化 vs 白化后提取，两者都报。

## 注入协议
- prefill + 每个 decode 步都加；
- 注入计数断言：**n + T − 1**（prefill 处理 n 个位置，之后 T−1 个 decode 步各一次；最后一个生成 token 不回灌）；
- 独立参照：无 KV cache 的整序列前向手动计数，必须一致。

## 系数网格
{0.5×, 1×, 1.5×} × 自然范数（‖mean diff‖），并报 {0.25×, 2×} 作边界。

## 阳性对照的通过线（写死）
- **诱导**：20 条良性提示，三个系数中至少一个使 ≥50% 被拒答，且重复率与非 ASCII 比例不异常；
- **消融**：20 条基座本来拒答的原始有害提示，做**所有层、所有位置**的方向投影消融，≥50% 转为合规；
- 若仅 layer 9 消融失败，不构成"方向有问题"的证据。

## 结果走向
- 全步有效 → C4 = "协议依赖"（全步有效、prefill-only 与随机无异；学出向量在 prefill-only 有效）；
- 全步无效 → 先查方向提取（白化、样本量、范数窗口），修好前不写 C4。

## 附录（UTC 时间见 PREREG_LOG）
### 选择集与提取集（不相交）
- 提取集：train_strat 中 60 条有害 + 60 条普通良性（vanilla_benign/keep60 普通请求）；
- 选择集：train 中另 37 条有害 + 40 条良性（不重叠），用于选层、位置、系数；
- 选择指标：全步协议下良性提示的诱导拒答率；过滤重复率>0.3 或非 ASCII>0.01 的配置；
- 阳性对照 20 条良性提示与选择集不相交；消融"转合规"用 HarmBench 判官（有害且合规），人工读 10 条确认非乱码；
- 位置取平均：最后 4/8 位置均值求方向；注入仍在所有位置 + 每个 decode 步。

## 修订 v2（追加，UTC 时间见 PREREG_LOG）
1. **选择指标统一**：正文"分离度最高者"即附录的"全步协议下良性提示的诱导拒答率"，并同时要求有害提示拒答率不下降、α=0 基线有害请求不被反向；不再有两个标准。
2. **双重留出**：选择集 37 有害 + 40 良性用于选 45 个配置（3 层 × 3 位置 × 5 系数）；选定后必须在**另一组不相交的 40 条 train 良性提示**上复测一次，避免选择集过拟合。
3. **有害侧检查**：阳性对照里同时报"有害提示拒答率是否下降"与"α=0 基座有害请求是否被反向"。
4. **消融方向**：用**同一个方向**（从选定层提取），在**所有层的残差**上做投影消融（Arditi 式），不是逐层不同方向。
5. **白化改为必做**：未白化与白化后提取两个版本都跑，用于排除"方向提取质量差"这一失败解释。
