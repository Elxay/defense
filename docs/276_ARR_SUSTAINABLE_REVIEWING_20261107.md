# ARR sustainable reviewing政策阅读记录

核对日期：2026-11-07。依据当前官方公告、CFP和qualifications；作者指南部分仍标旧周期，不能只按旧的“所有合格作者必须审稿”条款准备。

- 新政策从2026年10月ARR投稿起生效。评审容量受服务贡献约束；没有合格designated service contributor的稿件不保证获得评审，可能进入剩余容量抽签。贡献者可以是符合资格、愿意为论文背书的非作者。
- 每位designated contributor最多支持2篇。政策报告的每篇负担为5篇review或8篇meta-review；紧急情况由贡献者负责找合格替代，不能先报人名再假定会被豁免。
- 每周期每作者最多20篇投稿/重投，第一或共同第一最多5篇。所有作者和服务贡献者均需完整OpenReview资料：准确单位、职业阶段、邮箱、ORCID，以及适用的DBLP/ACL Anthology记录；仅邮箱注册不足。
- 当前自动资格：已获PhD/高级学术职位者需至少2篇认可主要会议/期刊论文；博士生或至少硕士学历的行业研究者通常需至少3篇认可主要会议/期刊论文。未自动合格者可作为受合格primary reviewer指导的secondary reviewer，不能自行充当designated contributor。具体认可venue按官方qualifications最新列表核对。
- 原先所有合格作者都必须审稿的要求被designated contributor制度替代。实施细节仍可能更新，提交前再核对官方页面。

本稿投稿前待办：确定作者列表；逐一核对OpenReview/ORCID；确定合格服务贡献者及其当期名额/可用性；按当前CFP重新核对目标周期、篇幅及必需Limitations。此次仅阅读并整理规则，没有代填资料、注册审稿或联系任何人。
