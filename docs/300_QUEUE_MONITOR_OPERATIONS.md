# GPU监视与就绪队列运行说明

每30秒采样；无compute上下文且显存<2GB连续15分钟写ready_queue/alerts.jsonl并打印IDLE_GPU_ALERT。包括已预留但尚无CUDA计算的CPU校验阶段，事件标reserved_by_job；有效租约仍阻止误派。innet GPU1排除。低利用率但模型持CUDA上下文不算空闲。

就绪集合只由明确前置元数据门生成；工程验收任务与正式生成任务分开。正式源解析器门失败不会启动10行。多卡高优先级任务就绪后，空闲的子卡预留给同一任务，防止低优先级任务反复抢回造成双卡永不同时空闲；若被外部作业阻塞则不空占另一卡。主生成按批次完整落盘后让位，zero20工程门按一次验收原子完成。

每次yield后保存现有输出SHA，续跑前核对SHA；控制器崩溃后由状态/描述符/exit恢复，死PID不会当有效租约。只有控制器可热更新，GPU worker不被中止。代码版本和catalog SHA均落盘。

当前告警交付是远端日志/控制台。Windows桌面前端被系统脚本执行策略阻止，未更改或绕过该策略，不声称桌面推送已启用。
